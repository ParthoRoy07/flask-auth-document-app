# Flask Authentication & Student Portal

A full-stack Flask web application implementing user authentication, password reset, and database-driven student grade management.

## 🚀 Features
- User registration and login system
- Session-based authentication
- Password reset functionality
- Dashboard after login
- Student grades stored in MongoDB
- Responsive UI using HTML & CSS

## 🛠 Tech Stack
- Python (Flask)
- MongoDB (PyMongo)
- HTML, CSS
- Jinja Templates

## ▶️ How to Run

1. Clone repository  

2. Install dependencies  
 
pip install -r requirements.txt


3. Start MongoDB server  

4. Run the Flask app  

python app.py


5. Open browser  

http://127.0.0.1:5000/
